# FOCAL LAB 안경원 노출 진단 — 배포 가이드

안경원 원장이 매장명을 입력하면, **실제 네이버 지역검색 API**로 상위 노출 현황을
조회해 "노출 진단"을 보여주는 리드 생성 도구입니다.

## 폴더 구조
```
focal-lab/
├── index.html          # 랜딩페이지 + 진단 UI (프론트엔드)
├── api/
│   └── place-rank.js    # 네이버 API를 호출하는 Vercel 백엔드 함수
├── vercel.json          # Vercel 설정
└── README.md            # 이 파일
```

## 배포 순서 (딱 3단계)

### 1. 파일 올리기
이 폴더(focal-lab)를 통째로 GitHub 저장소에 올리거나, Vercel에 직접 업로드합니다.
(기존에 vercel에 배포하던 프로젝트가 있다면, index.html을 이걸로 교체하고
 api/place-rank.js 파일을 추가하면 됩니다.)

### 2. 환경변수 등록 ★가장 중요★
Vercel 대시보드 → 해당 프로젝트 → Settings → Environment Variables 에서
아래 두 개를 등록합니다. (네이버 개발자센터에서 발급받은 값)

| Name                  | Value                          |
|-----------------------|--------------------------------|
| `NAVER_CLIENT_ID`     | 네이버 Client ID               |
| `NAVER_CLIENT_SECRET` | 네이버 Client Secret           |

⚠️ Client Secret은 백엔드(place-rank.js)에서만 씁니다.
   절대 index.html 같은 프론트엔드 파일에 넣지 마세요. (넣으면 누구나 훔쳐볼 수 있음)

### 3. 재배포
환경변수를 등록한 뒤에는 반드시 **Redeploy** 를 눌러야 값이 적용됩니다.
(등록만 하고 재배포 안 하면 계속 "진단 서버에 연결하지 못했습니다"가 뜹니다.)

## 네이버 개발자센터 설정 확인
- 애플리케이션에 **"검색" API 사용**이 추가되어 있어야 합니다.
- 검색 API는 별도 심사 없이 바로 사용 가능하며, 하루 25,000회 무료 호출 한도가 있습니다.
  (진단 도구 트래픽으로는 충분합니다.)

## 진단 결과가 보여주는 것 (실제 데이터)
- **노출 안 됨 (상위 5개 밖)**: 입력 매장이 상위에 없고, 대신 어떤 경쟁 매장이
  손님을 만나고 있는지 목록으로 보여줌 → 가장 강력한 상담 유도 훅
- **N위 노출 중**: 상위 5개 안에 있을 때, 몇 위인지 + 위/아래 경쟁 매장
- **검색 결과 0건**: 등록 자체가 안 됐거나 검색어를 못 잡은 경우

## 한계 (원장에게 정직하게 안내됨, dr-note에 명시)
- 네이버 지역검색 API는 **상위 5개까지만** 조회 가능. 6위 이하는 표시 안 됨.
- 이건 네이버 API 정책 제한이며, 정확한 순위·리뷰·유입 분석은 상담에서 제공.
- 실제 플레이스 순위는 검색 위치·기기·개인화에 따라 달라짐.

## 로컬에서 테스트하려면
정적 파일로 index.html만 열면 백엔드(/api/place-rank)가 없어서 "진단 실패"가 뜹니다.
반드시 Vercel에 배포한 상태(또는 `vercel dev`)에서 테스트하세요.
